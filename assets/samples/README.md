# 捏捏样例资源

四张 SVG 均为本项目于 2026-10-19 自行绘制的原创静态插画，没有使用参考博主的视频、截图、外部模型或贴图。通过圆润轮廓、渐变高光和柔和接触阴影表达软胶的体积与材质方向；不是正式 3D 资产，也不是已上线的可玩玩具。

资源保持透明背景，尺寸及 viewBox 均为 320×320，不包含外部链接、脚本、字体或持续动画，总体积很小。由首页的普通 img 懒加载，不增加常驻 WebGL 场景。

后续替换正式渲染图时，修改对应 img 的 src 和 alt，保留 `.sample-art` 的方形占位及 img 的 width/height，避免加载改变布局。SVG 也可直接换为透明 PNG/WebP；新的造型比例不同时需重新检查桌面、手机轮廓及命中区域。`showcase.js` 在图片失败时隐藏破损图片并显示同尺寸替代文字。
