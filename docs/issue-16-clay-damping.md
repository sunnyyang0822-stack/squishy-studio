# Issue #16：黏土整体提高交互阻尼

2026-10-22，用户明确要求小幅增加黏土阻尼，尤其避免滑动时凹陷过快、过猛。基线为最新 `origin/main` `e6bb15b7b2827da27eded4bfa0c2224a63308905`，分支 `codex/issue-16-clay-damping`。沿用现有详情页单屏适配，不改布局、灯光、颜色、资产或依赖。

## 共用实现的两处修订

`src/orb-deformation.mjs` 是 `getOrbFeel('clay')` 使用的工厂，因此所有调用黏土的兼容样式统一生效，不设置仅当前页面使用的覆盖参数。

- 按住或滑动时一阶响应系数 **7/s → 5/s**，形变继续立即反馈，但逐步深入。减少动态模式原先按住时16/s偏快，现在按压同为5/s；减少动态仍按原规则加快释放收束。
- 拖动位移额外增压上限 **0.04 → 0.02**。时长映射、邻域、连续路径采样及软限制不变。
- 松开仍保留85%新增压痕；释放响应正常10/s、减少动态16/s，换色0.65s/0.12s共用时钟和中断规则不变。没有延迟输入、整球缩放或新的物理系统。

## 风险、节点与回滚

降低响应系数是受控视觉阻力，不代表真实黏土应力。减少动态下按压比之前明显减缓，用于统一材料阻力；真实设备触感仍需负责人复核。调用入口继续见 [质感复用](orb-feels.md)。正常revert本次提交并重建即可回到前版黏土参数，无数据迁移。关联 #16，交付阶段一；仍停在1B体验评审，不进入碎裂或声音、不关闭整个Issue16。
