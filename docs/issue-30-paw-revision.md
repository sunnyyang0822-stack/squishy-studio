## 外形

以用户提供的猫爪照片为比例和形状参考：四个饱满椭圆趾垫；中央是朝趾端充分钝圆、下方双圆瓣的倒心形主垫。外掌保持圆厚体积，趾根加宽并自然融入掌体。主垫是有厚度的实体曲面，经过体素融合去掉内部壳；颜色、灯光或法线平滑不能替代真实凸起几何。

资产源文件位于 `assets-source/squishy-paw/`，运行时为 `assets/models/squishy-paw.glb`。`scripts/build-styles.py -- paw` 在独立后台 Blender 中复现源文件、GLB、正侧背底图和几何统计。不得在用户未保存的交互场景中执行。

## “按这里，旁边动”的根因与修复

原适配为每个三角形假设八种独立极端位移组合。这个保守的盒约束把大量细三角形允许的压入半径降到约千分之一模型单位，随后只减不增的平滑又把小上限传播到邻域。旧回归只检查全模型最大位移，无法发现实际命中点几乎不动。

猫爪现在沿连续厚度方向受压，使用实际候选位移的局部几何安全投影。每个三角形沿本帧实际位移段的有向面积是二次多项式，检查第一个危险根而非仅检查终点。危险面只收缩自身三个顶点的增量，再检查相邻面；旧足迹达到限制时，其他区域仍能继续按入。接受状态还须保留通往原始网格的安全恢复路径。原三角形投影面积至少保留 8% 的断言未移除。

曾试过全局缩放本帧全部增量，但独立审查发现旧趾垫饱和后会阻塞滑到的新区域，因此没有将它作为最终方案。局部求解修复后，同一笔从饱和左趾移到右掌及背面，可以继续在新接触点产生明显位移。

这个变化只约束空间几何。黏土强度、阻力、响应、85% 新增留痕、取消和换色恢复参数沿用原模板。未提供可选几何安全回调的原圆球继续走原分支。甜甜圈仍保留原有不跨孔的测地邻域与安全盒，不受猫爪专用求解分支影响。

视觉复查发现仅沿网格边的 Dijkstra 距离会在深压曲面上放大细碎褶皱。猫爪现在使用三角形内部传播的一阶 Fast Marching 邻域；仍沿连接表面传播，不用欧氏距离跨过孔隙或背壳。大角度法线跳变边的对照数量降低约20–24%，但最大单边法线差并未显著降低，因此不把这个统计当作“任意深压完全无褶皱”的证明。解析平面、背面隔离、真实104次深压及实际浏览器前后对照共同验证本次修正。钝角/非因果三角形回退单边，有限网格仍有离散误差；原半径、时序及安全参数不变。

## 局限与回滚

几何安全约束保留闭合网格的局部面方向及厚度边界，不是任意操作下所有远隔面自交的完整证明。手机范围是桌面浏览器触屏模拟，CPU 求解时间和 GPU draw 间隔均不能当作真机 FPS、温升或功耗结论。

回滚时正常 revert 本轮 PR 的合并提交，成对撤销猫爪 `.blend`/GLB、几何适配和运行时构建产物；棉花糖预设整合随本 PR 一起撤销。没有数据迁移，不改写共享历史。
