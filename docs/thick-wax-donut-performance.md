# 甜甜圈厚蜡交互性能优化（Issue #43 / PR #52）

用户反馈甜甜圈厚蜡交互卡顿，本次只针对 `thick-wax` + `styleId: 'donut'` 默认启用脱落片正间隔证书，并修复原大曲片碰撞校正次数不足的安全边界。薄蜡与其余厚蜡样式默认保持原完整查询路径和原10次校正上限。仍使用内圈大分区、0.042局部实体厚度、0.004壳芯间隔，黏土手感、损伤时序、落片数量/速度、完整体积与边缘防穿模约束均不修改。

分支 `codex/issue-43-thick-styles`，前一审查版本提交 `ec65e53`，本次在同一个未合并PR #52内追加独立优化提交。主线基线仍为圆球验收合并 `a9315d9`，猫爪排除。仓库Public，不自动关闭#38/#41/#22。

## 定位与实现

通过真实GLB内壁接触的独立CPU采样，确认主要耗时为脱落大曲片逐样点的最近面BVH搜索：优化前厚蜡signedDistance累计约3.13秒；每帧约540524个BVH节点访问，脱落片最近面查询7619次。大碎块没有更改数量，但完整曲片覆盖更多原始三角面，内部面心/边检查较多。

本轮保留所有样点及原顺序（内外顶点、真实三角面心、三条边中点），不减少面或碰撞点、不改变内外几何。每个样点记录最近一次精确查询的正间隔、局部位置和内芯累计运动上界。只有满足：

`旧正间隔 - 样点位移 - 内芯累计运动上界 > 0.003 + 1e-9`

才能证明该实际样点仍在外侧且超过原校正阈值，从而省去重复最近面搜索。否则立即执行原精确查询及刚性整片校正。不会返回旧距离，也不缓存施力或损伤状态。内芯运动上界来自现有BVH每次refit的最大顶点位移累加，以相同重心坐标界定每个活动三角面Hausdorff运动；无可靠上界时不复用。

证书使用内芯局部坐标，因此旋转、位移和缩放后的碎片位置差同样计入失效条件。内芯突发恢复、样点法线改变及校正均以实际当前样点位置重新界定。重开、过期清理及dispose释放证书。适用条件为本轮已验证的闭合无自交资产，不能把最近面法线符号实现泛化为任意开放/自交几何的全局距离定理。

调用可显式关闭：`getWaxPreset('thick-wax').create({ styleId: 'donut', detachedClearanceCertificates: false, ... })`。关闭时回到未优化算法。工厂只对厚蜡甜甜圈默认true；薄蜡、圆球和其他款默认false。

## 原碰撞校正预算不足的修复

新录屏捕捉到一次15个脱落样点穿入，最小距离-0.00555。追踪后在**关闭证书的原10次校正路径**稳定复现：90Hz、内壁连续按压第190帧148处穿入，最深-0.00898786，最坏为真实inner-vertex。60Hz/30Hz/.02秒步长也存在原路径穿入。原始失败日志和复现记录均保留，不删除或放宽断言。

仅厚蜡甜甜圈将单片校正**上限**10提高到40，每轮仍检查全部原采样点并在安全时立即退出，不是固定多做30轮，也不新增速度/爆裂力。新预算同一复现帧0穿入，独立完整内外体积292264次采样最小距离0.0023944，局部厚度仍为0.042。新增worstDetachedSample仅用于诊断。上限入口必须为10–64整数，不能通过传入0绕过检查。

证书开/关的严格几何等价对照使用**相同40次安全预算**，隔离缓存优化与安全修复；不声称修复后仍与原有穿模几何一致。

## 验证

新增 `tests/wax-detached-clearance.test.cjs`，开关优化的两个实例共同跟随同一个真实黏土GLB内芯，逐帧比较上传的**每个Float32顶点和法线、所有损伤/落片/清理状态完全相同**。场景包含孔内深压、拖动、旋转、重复按压、突发完整内芯恢复、非均匀缩放和位移、渐进恢复、过期清理及重开。证书不能只通过“没有穿模”而改变原效果。

最终可变步长（144/90/60/30Hz、55ms、100ms交替）等价对照包含197个活动碎片帧、约331万命中证书，实际最近面查询4253946→941928，降低77.9%；记录于 `final-regression.txt`。最终相关回归64/64通过、退出0，包含六款独立完整几何、薄蜡、内芯、缓存、流程及本轮两个专项。现有完整体积样式测试继续独立对内外面、顶点、边及侧壁做真实查询，不使用证书作为验证器。

对应命令和退出码见 `commands.txt`、`regression.txt`、浏览器及录屏验证输出。旧六款证据保留其原bundleSHA，新优化甜甜圈单独归档，不把旧录屏冒作新构建。最终优化bundleSHA256：`0f771cb26cd1cefb8314440f47348b749caca9034c0e8da0464cadb8268b4147`。
