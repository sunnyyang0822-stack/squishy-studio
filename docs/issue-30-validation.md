# Issue #30：新增样式的独立验证

本轮按产品后续指示仅验收七种新增样式 × `clay`，不将其他内芯偷偷映射为黏土。原圆球及现有质感回归由仓库原测试继续约束。花朵按最新产品评审为五个花瓣球 + 一个中心花蕊球；猫爪为四趾 + 一个倒心形主垫；三角锥采用圆钝四面体。

## 可复现命令

```powershell
npm run build:orb
node --test tests/squishy-styles-assets.test.cjs tests/squishy-styles-surface.test.cjs
node --test tests/squishy-styles-browser.test.cjs
$env:PORT='4199'
node server.mjs
# 在另一终端，服务器运行时：
$env:PREVIEW_URL='http://127.0.0.1:4199'
node capture-styles.cjs
node scripts/observe-styles-performance.cjs
```

本地完整回归 `npm run build` 后执行 `node scripts/test-port-isolated.cjs`（22 个测试文件，仅隔离端口）**152/152 通过、退出码 0，耗时 429.245 秒**，原始日志见 [final-tests.txt](../artifacts/issue-30/final-tests.txt)。首轮 141/152 的失败日志保留于 [full-tests.txt](../artifacts/issue-30/full-tests.txt)：扩展大厅后的链接定位歧义、旧圆球返回 URL/辅助文字兼容，以及测试错误地在返回内芯后再点击隐藏返回按钮，均已修复；原有行为断言保留。本页只声称下面实际执行的检查。捕获脚本遇到真实形变、恢复、触摸滚页、资源错误或灯光阈值失败时退出非零，不把静态截图当成交互验收。

## 检查方法

- 直接读取运行时 GLB：有效有限坐标、单位法线、三角形面积与朝向、实际厚度、顶点/三角形/字节预算；坐标焊接后无边界或非流形边、单连通表皮，甜甜圈欧拉特征为 0，其余为 2。没有以 Blender 源场景替代导出物。
- 使用真实 GLB 顶点调用几何适配：七款分别在四处表面各长按六次并轻移，检查所有三角形不塌陷、黏土 85% 留痕、取消及精确恢复原始形态。星形可参数化表面额外逐项验证原始闭合 genus 0、原始每面关于中心行列式为正、变形顶点保持原射线且尺度严格为正、变形后每面行列式与面积仍为正，保持原有一一对应的球面投影。其余法线厚度适配保留每面相对原始朝向点积为正的保守断言。甜甜圈检查同 Y 的直接对侧孔缘不变，以及中心射线不被变形三角形封住。足迹可沿真实表面绕到邻近圆弧，这与直接跨孔不同。
- 等价球空间查询与原黏土调用逐帧比较位置、状态、调度结果；按住、滑动增压、释放、取消和恢复严格相同。几何适配没有重新调节这些行为参数。
- 浏览器拦截真实 WebGL 顶点上传与目标网格 draw 调用，确认真实局部凹陷、滑动与释放留痕、换色恢复、颜色实际显示、输入取消、旋转和离页释放。七款均走完五步进入最终试捏、返回修改及刷新保持样式；甜甜圈键盘操作会命中真实环体。延迟旧样式请求后快速切换，只允许最后选择提交，并检查旧 GPU 上下文释放；伪 HTML 模型响应会失败且可重试。
- 旋转检查使用目标网格当前 program 的 model-view 矩阵乘原始几何中心，连续多方向拖动保持中心误差小于 `1e-5`；不使用会自然变化的屏幕轮廓包围盒中心。
- 昼/夜各看正、侧、背、底四个朝向。真实 `readPixels` 在网格绘制时读取表面，alpha ≥ 254 排除透明背景和半透明接触阴影，要求表面亮度第 5 百分位大于 30/255，近黑像素（最大 RGB < 24）少于 0.5%。同时保存截图人工复查。该阈值防止面整体变黑，不等于对所有无限连续角度的数学证明。
- 手机为 Edge/Chromium 的 390 × 844 触屏模拟：通过 CDP 原生 `touchStart/Move/End` 操作真实页面，确认压痕、释放、换色复原和页面不随拖动滚动。没有使用真机，不能声称真机性能通过。

捕获报告中的 `desktopRenderIntervalsMs/mobileRenderIntervalsMs` 实际取相邻目标网格 `drawElements` 调用的间隔，并排除了大于 250 ms 的静止/操作停顿。同一帧可能包含多个渲染 pass，因此它不是完整帧耗时，不能倒数换算 FPS。本轮捕获与主进程的顺序测试同时运行，最多两套浏览器共享开发机 GPU；录屏、截图、GPU 探针和桌面触摸模拟也会影响数值。表中的间隔仅用于记录此负载下的原始观察，不代表手机性能达标。暂无真机温升、低端 GPU 长时功耗和触摸硬件延迟数据。

几何风险在验证中实际发现并修正：最初逐点厚度/曲率限制在反复深压时产生面折返；补充三角形极值界限后不再翻转。之后实际截图仍显示孤立细小尖坑，进一步对几何安全界限作只减不增的邻域平滑。经确认满足星形可参数化前提的表面采用共享黏土的正径向尺度和测地邻域，保留宽凹陷；甜甜圈继续法线/厚度安全限制。猫爪按厚度轴（glTF Z）形成连续压入方向场：前后肉垫沿厚度方向压入，侧缘连续过渡；所有三角形仍保留安全界限，未放宽原面朝向断言。最初统一使用“变形面法线与原始法线点积为正”会把合法深谷侧壁超过 90° 的转向误报为翻面；改为上面更准确的径向全局不交叉约束，原圆球测试不变。最终证据由最终构建重新捕获，旧失败图不能计作最终通过证据。

猫爪另暴露出原始导出法线与 Three.js 静态重算法线不一致：几何完全未动时最大差 17.63°、132 个顶点差大于 5°，一旦局部按压触发全网格重算法线，远处趾垫也会突然出现细波纹。新增表面使用导出法线加上“变形重算法线 − 静态重算法线”的归一化增量；GPU 回归同时观察真实法线缓冲，要求远处位置未变的皮肤法线保持误差小于 `1e-5`。原圆球不进入该新分支。

猫爪最终几何安全适配的补充观察：主肉垫典型长按最大位移约 `0.0437`，趾垫连接处约 `0.02451`（模型单位为米）。连接处未达到通用审阅脚本的 `>0.03` 可见深度门槛，因此不声称此项通过该门槛；保留安全深度限制，没有为更深的视觉效果放宽三角形有效性断言。`paw-connection-review-pressed.png` 与 `paw-side-review-retained.png` 保存实际限制下的画面。该局限须与常规流程的通过结果一起阅读。七张 `*-review-*` 补充图来自猫爪冻结提交 `cfcdf59`（相同 GLB；当时 bundle 为 `b9b13709...`），仅用于观察该局限，不计入最终 161 张标准截图或最终哈希验收。

## 范围与回滚

本页不声称 21 种组合通过，不声称新样式的棉花糖/慢回弹已验收，不把 GLB 加载成功等同可玩通过。几何测试是有限采样与安全约束回归，不替代所有可能连续操作下的完整自交证明。

测试与捕获脚本独立于运行时；回滚相应交付提交并重新构建即可恢复基线，旧圆球 GLB 和已确认质感参数不在本验证提交中修改。最终 commit/PR、全量本地测试与 GitHub 必需检查由主交付说明汇总。
