## 复用

稳定ID仍为 `slow-rebound`。`src/orb-slow-rebound.mjs` 的 `slowReboundParameters` 是唯一默认参数来源；`getOrbFeel('slow-rebound')` 与 `getOrbPreset('slow-rebound')` 使用同一独立工厂。场景不再为圆球传入第二套调参。旧导出 `slowReboundOrbDepthLimits` 仅保留兼容别名，值来自同一参数对象。

```js
createOrbPreview(mount, { styleId: 'orb', presetId: 'slow-rebound' });
// styleId也可用cloud、paw、cylinder、donut、pyramid、flower、star。
// 已有场景直接getOrbPreset('slow-rebound').createDeformation(positions, normals, geometryOptions)。
```

制作页及最终试捏均通过配方 `coreMaterial: 'butter'` 取得同一预设；已支持的薄蜡、厚蜡和指甲油组合继续复用此内芯工厂，不另存慢回弹参数。其他内芯及外壳预设不修改。自定义模型仍需提供并验证几何适配，不能仅凭ID保证安全深压。

## 实际参数

| 项目 | 确认值 | 用途 |
| --- | --- | --- |
| 足迹半径 | .48模型单位 | 强调深度，缩小原.60范围 |
| 按入速度 | 1.05单位/s | 120ms柔和起步，随后匀速深入 |
| 最大深度 | 1.80 | 中央长按约2秒达到深压，受几何安全限制 |
| 径向限深 | .92半径 | 无射线调用保留至少8%半径 |
| 方向限深 | 1.85半弦长 | 射线调用保留至少7.5%前后完整弦长 |
| 集中度 | 100 | 对数坑壁，集中压深 |
| 坑底平滑 | .30 | C2内侧映射，圆缓盆底；不扩大足迹 |
| 外肩比例 | .10 | 接回原表面时一、二阶导数归零 |
| 滑动速度/限深 | 1.1 / .20 | 保持浅滑痕，不将长按深度带到新位置 |
| 起步/拖动宽限 | .12s / .12s | 不瞬陷，稀疏移动后继续推进 |
| 松手恢复 | .80/s | 保留用户确认的回弹感觉 |
| 减少动态恢复 | 5/s | 缩短恢复，不改变渐进按入 |
| 精确收敛 | .00001单位 | 小残差归原始Float32坐标，随后停帧 |

静止接触令 `q²=表面距离²/.48²`，`t=min(1,q²/.30)`，以 `q²*t³*(10−15t+6t²)` 进入对数坑壁函数。只改变内侧约.263单位的底壁衔接，外侧足迹不增大。复杂样式使用沿真实表面的距离，同一函数、速度与回弹；几何限深各自约束薄处，不硬套圆球的1.80行程。

圆球贴边仍使用真实命中。视线与局部法线夹角经C2过渡，方向最多向局部法线偏65%，接触深度系数从极边缘.78到中央1，减少侧向拉口。移回中央从当前网格连续深入，不重置旧痕。球体使用可选整体安全投影及动态面坐标，避免逐面截断形成棱角；旧黏土默认安全路径完全保留。

## 恢复与生命周期

自动恢复与显式换色恢复互斥：`beginRestore/applyRestore` 时由既有换色时钟独占；新输入/`interruptRestore` 连续接管当前形态。取消只结束施力，旧、新压痕全部自然归位。`reset` 清理形变、接触计时、路径和深度系数，不会下一帧冒出旧痕。后台结束接触并暂停，前台从当前形态恢复，不追赶后台墙钟。每实例独立分配状态。

恢复完成定义为所有POSITION逐值等于加载的原始网格；误差严格为0。最大1.80以.80/s衰减到1e-5，理论尾部约15.13秒，几何测试给16秒上限，不调用reset伪造恢复。最终收敛位移不超过约1.01e-5单位（350px/单位下约.0036px）；完成后 `needsFrame:false`。不同采样最大坐标差限定.011单位，约为无射线.92安全深度的1.2%，实测30Hz差.01019、120Hz差.000062、10Hz事件差.00491；这是深压与拖动驻留切换的离散误差，不宣称严格物理等价。

## 风险与回滚

这是受控视觉近似，不是材料物性模拟。薄边可达深度受资产与局部几何限制；复杂形状和不同按压位置不会有完全相同的绝对深度。深压对既有外壳会产生更大的支撑变化，沿用其现有支撑、恢复和安全逻辑，完整测试与CI作为合并门禁。

回滚本PR的源文件、测试与文档并重新运行 `npm run build:orb`，即可恢复旧慢回弹默认；无需模型或数据迁移。不要回滚其他协作者的薄蜡、灯光或指甲油提交。
