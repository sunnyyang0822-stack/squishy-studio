# 捏捏原色与控件动效优化

关联 #8、#10，本次不关闭这两个阶段 Issue。基线为 `origin/main d529f377248fafd5ca87224d84d3cd116c18be5f`，独立分支 `codex/toy-colors-motion`。

## 变更

| Before | After | Why |
| --- | --- | --- |
| 详情、第二屏和大厅的捏捏夜间使用brightness／saturate滤镜 | 移除图片滤镜及filter过渡，直接使用原始素材 | 保持奶白、粉桃、薄荷和奶黄原色；环境仍延续已有夜间色调 |
| 音量面板直接显隐 | 180ms展开、120ms收起，右上方为过渡起点，位移不超过4px、缩放不低于.98 | 明确面板与按钮的空间关系，保持轻柔和即时反馈 |
| 连续操作没有过渡衔接 | 从当前计算得到的opacity／transform继续，可中途反向 | 不重置到起点；关闭立即inert和aria-hidden，焦点及时返回入口 |
| 单选缺少按下反馈 | 140ms、.97缩放；勾选与配置立即更新 | 反馈操作，不延迟高频选择，也不让玩具发生假捏压 |
| 厚度与材质的选中背景直接跳换 | 两组独立的200ms滑动底块，连续选择从当前位置继续 | 按负责人追加要求体现滑动感；保留原生单选、勾选标记与即时配置 |
| 大厅入口hover变化阴影、触屏也触发hover | 仅精确鼠标hover时箭头移动3px，入口轻微按下；键盘聚焦时取消箭头运动 | 目的明确，避免粘滞hover和不必要绘制 |
| 第二屏小字跟随长色彩过渡 | 字色220ms过渡，无文字模糊或透明叠加 | 尽快清晰可读，保留背景与托盘原有昼夜节奏 |

遵循用户指定的emil-design-eng技能。键盘打开、关闭及Esc即时完成；减少动态时面板不位移、不缩放，偏好在动画中改变也会立即收束。不增加玩具悬浮、按压或持续装饰动画，不修改首页Hero、字标和原有主题参数。

`detail/panel-motion.js`单独管理一个Web Animations API动画，使用`cubic-bezier(.23,1,.32,1)`，只动画transform与opacity，不引入依赖。读取当前状态后取消旧动画，旧完成回调不能隐藏重新打开的面板。`pagehide`的既有AbortSignal清理动画和动态偏好监听。收起时保持文档流占位至淡出完成；小屏面板始终不覆盖主体。

## 走查与回滚

`npm start`后访问 `/squishy/cloud/` 或 `/#samples`，昼夜切换入口仍在首页顶部。证据位于`artifacts/toy-colors-motion/`，重新采集运行`node capture-toy-colors.cjs`，可用`PREVIEW_URL`指定本地服务。

当前依然只有静态玩具外观，没有新增GLB或声音。SVG透明阴影会正常与昼夜背景合成，但主体素材的颜色没有被整体压暗或染色；不同背景造成的主观对比感不等于纹理被修改。
