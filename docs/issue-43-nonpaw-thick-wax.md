# 非猫爪造型厚蜡接入（Issue #43）

起始基线为 `origin/main` 的 `b65038c`，后续已同步 `fa68f6c` 的统一慢回弹交付并重新验证。起始基线包含已确认厚蜡 PR #54、圆球比例/光照、指甲油与非猫爪薄蜡支持。2026-11-05 用户授权将当前厚蜡套用到其他样式，“除了猫爪三个样式”按猫爪的三种内芯组合均排除执行。本分支为 `codex/issue-43-thick-non-paw`，独立工作树位于项目根目录内。

## 范围与调用

圆球既有三内芯保持，新增云朵、圆柱、甜甜圈、三角锥、花朵、五角星 × 黏土(clay)、棉花糖(marshmallow)、慢回弹(slow-rebound，配方butter)，共18个新增制作预览组合。猫爪三个内芯均不启用厚蜡。稳定调用仍为 `getWaxPreset('thick-wax').create(options)`，不新增场景或内芯工厂。

本轮仅扩展外壳/装饰制作预览；只有原黏土圆球保留既有最终带壳体验。其他最终试捏沿原裸芯行为，内芯恢复时保留隐藏制作壳破损，返回制作仍显示原破口。不把制作预览通过视作最终厚壳交互验收。默认配方、布局、颜色及原薄蜡/指甲油映射保持。

Issue原文仍写“基于中度蜡”，本轮遵循产品负责人明确基线调整：厚蜡直接基于已确认薄蜡共享工厂，不依赖中度蜡，不改写中蜡分支。旧六款黏土厚蜡PR #52仅作只读参考，不整体合并，不覆盖其分支。

## 几何与行为约束

复用已确认参数：每处局部实体厚度0.042模型单位（薄蜡0.014的3倍），初始gap0.004，厚蜡向内随动上限0.004以保留原弧面。内芯位置与安全约束优先，内芯下陷后的自然空隙不是实体厚度。尺寸变化只能来自实际分区，不能缩放脱落片。甜甜圈内圈统计单列，验证不能仅看全局均值。

复用原输入、0.5秒驻留、损伤保留、释放停止施力、碎片掉落清理和资源生命周期。三种内芯的工厂与参数保持。非圆球棉花糖/慢回弹显式开启原有fullSurfaceSupport，黏土保持原分支，完整检查内/外面、边与断面，防止大碎片漏检。

## 风险与回滚

非凸连接和内圈对厚壳大碎片更敏感，需独立完整体积证据。性能仍以实际记录为准，不宣称稳定60fps或把模拟成绩当真机成绩。回滚本PR提交并 `npm run build:orb` 可恢复已确认圆球厚蜡范围，无数据迁移，不改共享历史。仓库保持Public。

独立审查修正了几何夹具：必须与宿主保持相同的 authored rest normal、形变法线差量和静止恢复；慢回弹方向须依据相机朝向与当前模型逆矩阵计算，含三角锥初始旋转。此前简化夹具的15项通过及甜甜圈10/40/160次试验均仅作诊断历史，不能作为最终产品几何验收。原始失败输出保存在diagnostics/并标注条件，最终采用宿主一致夹具重新验证。

厚蜡非圆球的片面命中使用实际当前三角形最近距离，解决大碎片覆盖点击位置但片中心超出旧半径时不立即开裂的问题；仅非圆球厚蜡启用，薄蜡和已确认圆球保留原选择路径。圆柱黏土/慢回弹在原生pointerdown、内芯depth=0时即可看到裂纹，随后真实GPU短按仍小于0.5秒且无脱片，2/2通过，见cylinder-first-click-final.txt。

非圆球厚蜡脱落片使用真实内/外顶点、面心、边中点和断面样本；多面接触时将当前接触法线半空间约束作为整体刚体平移候选，再以完整几何重查，避免只追逐最深一点在内圈来回修正。保持原重力、速度、时间、初次掉片数和实体厚度，不通过缩放或弯折碎片解决碰撞。原包围盒快速排除及安全距离证明保留；无法证明安全的样点仍重新查询。当前甜甜圈碰撞预算上限40且满足安全条件即提前退出，其他造型沿原10，不能将预算上限当作每帧固定执行次数。
