# 非猫爪造型厚蜡接入（Issue #43）

起始基线为 `origin/main` 的 `b65038c`，后续已同步 `fa68f6c` 的统一慢回弹交付并重新验证。起始基线包含已确认厚蜡 PR #54、圆球比例/光照、指甲油与非猫爪薄蜡支持。2026-11-05 用户授权将当前厚蜡套用到其他样式，“除了猫爪三个样式”按猫爪的三种内芯组合均排除执行。本分支为 `codex/issue-43-thick-non-paw`，独立工作树位于项目根目录内。

## 范围与调用

圆球既有三内芯保持，新增云朵、圆柱、甜甜圈、三角锥、花朵、五角星 × 黏土(clay)、棉花糖(marshmallow)、慢回弹(slow-rebound，配方butter)，共18个新增制作预览组合。猫爪三个内芯均不启用厚蜡。稳定调用仍为 `getWaxPreset('thick-wax').create(options)`，不新增场景或内芯工厂。

本轮仅扩展外壳/装饰制作预览；只有原黏土圆球保留既有最终带壳体验。其他最终试捏沿原裸芯行为，内芯恢复时保留隐藏制作壳破损，返回制作仍显示原破口。不把制作预览通过视作最终厚壳交互验收。默认配方、布局、颜色及原薄蜡/指甲油映射保持。

Issue原文仍写“基于中度蜡”，本轮遵循产品负责人明确基线调整：厚蜡直接基于已确认薄蜡共享工厂，不依赖中度蜡，不改写中蜡分支。旧六款黏土厚蜡PR #52仅作只读参考，不整体合并，不覆盖其分支。

## 几何与行为约束

复用已确认参数：每处局部实体厚度0.042模型单位（薄蜡0.014的3倍），初始gap0.004，厚蜡向内随动上限0.004以保留原弧面。内芯位置与安全约束优先，内芯下陷后的自然空隙不是实体厚度。尺寸变化只能来自实际分区，不能缩放脱落片。甜甜圈内圈统计单列，验证不能仅看全局均值。

复用原输入、0.5秒驻留、损伤保留、释放停止施力、碎片掉落清理和资源生命周期。三种内芯的工厂与参数保持。非圆球棉花糖/慢回弹显式开启原有fullSurfaceSupport，黏土保持原分支，完整检查内/外面、边与断面，防止大碎片漏检。

## 风险与回滚

非凸连接和内圈对厚壳大碎片更敏感，需独立完整体积证据。性能仍以实际记录为准，不宣称稳定60fps或把模拟成绩当真机成绩。回滚本PR提交并 `npm run build:orb` 可恢复已确认圆球厚蜡范围，无数据迁移，不改共享历史。仓库保持Public。

独立审查修正了几何夹具：必须与宿主保持相同的 authored rest normal、形变法线差量和静止恢复；慢回弹方向须依据相机朝向与当前模型逆矩阵计算，含三角锥初始旋转。此前简化夹具的15项通过及甜甜圈10/40/160次试验均仅作诊断历史，不能作为最终产品几何验收。原始失败输出保存在diagnostics/并标注条件，最终采用宿主一致夹具重新验证。

厚蜡非圆球的片面命中使用实际当前三角形最近距离，解决大碎片覆盖点击位置但片中心超出旧半径时不立即开裂的问题；仅非圆球厚蜡启用，薄蜡和已确认圆球保留原选择路径。圆柱黏土/慢回弹在原生pointerdown、内芯depth=0时即可看到裂纹，随后真实GPU短按仍小于0.5秒且无脱片，2/2通过，见cylinder-first-click-final.txt。

非圆球厚蜡脱落片使用真实内/外顶点、面心、边中点和断面样本；多面接触时将当前接触法线半空间约束作为整体刚体平移候选，再以完整几何重查，避免只追逐最深一点在内圈来回修正。保持原重力、速度、时间、初次掉片数和实体厚度，不通过缩放或弯折碎片解决碰撞。原包围盒快速排除及安全距离证明保留；无法证明安全的样点仍重新查询。当前甜甜圈碰撞预算上限40且满足安全条件即提前退出，其他造型沿原10，不能将预算上限当作每帧固定执行次数。

## 交付验证

最终集成基线为 c34a851（PR #58）。该主线已提供中蜡，厚蜡仍由薄蜡参数派生。三档制作预览与重开各自登记，非圆球最终试捏使用原有裸芯流程。合并后 30 项流程与预设测试通过。

在 fa68f6c 集成构建上，正常模式 18/18、减少动态 4/4、相关回归 152/152、真实浏览器 25/25 通过。正常模式对照 9,645 帧内芯坐标及状态，对真实内外三角、边中点和断面采样 80,811,136 次（42,899,124 次独立距离查询），最小正间隔 0.0014982，局部厚度最大误差 4.64e-7，附着内凹最大值 0.0040665。首次分离前后逐帧检查，其他动作以记录的采样帧为准。后续录屏在甜甜圈棉花糖长按时发现原迭代上限仍可能留下少量穿入，见旧录屏报告。为该造型补充了多接触修正未收敛时的刚体安全位置复核。优先重新检查本帧修正位置，再检查上一安全姿态，两者都失效时查找周围有效位置。大幅避让只在局部无法容纳该碎片时使用，因此边缘极端接触可见瞬时避让。

六款新增造型厚蜡均有 36 个连通分区。云朵、圆柱、三角锥、花朵、五角星的整体平均真实碎片面积约为薄蜡 5 倍，等效直径约 2.24 倍。甜甜圈的薄蜡有 260 或 271 个连通分区，厚蜡平均面积为 7.22 至 7.53 倍。对采用较紧凑薄蜡分区的慢回弹甜甜圈，实际接触内圈的碎片平均面积、中位面积与第十百分位面积分别为薄蜡 6.99、7.36、6.38 倍。统计单位为模型单位平方。真实源三角逐面覆盖和三边刚性检查详见几何报告。

## 甜甜圈棉花糖长按优化

同一内圈触点持续按压时，碎片会同时接触凹面的两侧。旧求解最多做 40 次整体平移，每次都可能重新查询内外表面和断口。甜甜圈棉花糖厚蜡现在每块碎片每次求解最多做 4 次平移。首轮仍以 0.003 模型单位为净空目标，后续可在完整碎片达到已有的 0.0005 安全阈值时退出。未达到阈值时沿用原来的安全姿态搜索。每个样点均由精确查询或保守运动距离证明覆盖。薄蜡、中蜡及其他厚蜡组合沿用原碰撞预算。

内圈仍接触 22 块厚蜡碎片，平均整片面积为 0.3480 模型单位平方，对应薄蜡为 0.0328。实体厚度保持 0.042。110 帧确定性复现逐帧核对掉片时序与数量，单帧碎片距离查询峰值从 63,792 降至 34,094。第 78、80、83、87 帧独立复核了真实内外面、断口、顶点和边缘，最小正间隔为 0.0005054 模型单位。

与 1762c5e 旧包做 5 轮交替 A/B。Edge 的 390×844 模拟触摸使用同一模型、配色、视角、白天光照和内圈触点，持续按压 4 秒。每轮 P95 的中位数为 116.3 → 50.7 ms，P99 的中位数为 175.4 → 99.2 ms，全轮最大间隔为 186.3 → 158.9 ms。这是本机浏览器渲染完成间隔，仍有长帧。手机真机与 Safari 待测。原始采样、对照录屏与复现命令见 `artifacts/issue-43-nonpaw/donut-marshmallow-review/`。

再次复现时，首帧附着壳检查和长按期间碎片接触分别出现长帧。甜甜圈棉花糖厚蜡现在共享邻近采样点的保守净空下界，并复用现有的增量碰撞网格。只有下界严格大于当前净空阈值时才跳过精确查询，原采样位置、碰撞修正和碎片刚体几何继续使用。133 帧前后对照的位置、法线及损伤状态逐帧相同，覆盖按下、分离、内圈拖动、松手和旋转。

以 `98c5557` 作为同批 A/B 基线，模拟触摸五轮的长按 P95 中位数从 68.1 ms 降为 26.6 ms，桌面鼠标三轮从 81.3 ms 降为 28.0 ms。两种输入合计超过 100 ms 的长按间隔从 30 次降为 0 次。桌面最长长按间隔为 391.9 → 58.6 ms，模拟触摸为 321.6 → 52.6 ms。原始数据、各阶段计时和新录屏见 `artifacts/issue-43-nonpaw/donut-marshmallow-followup/`。
