# 圆球展示页单屏适配 · 关联 #10、#16

## 基线与范围

基于 `origin/main 773c1dd` 建立独立分支 `codex/detail-single-screen`，在 `D:/squishy-studio-single-screen` 的独立工作目录开发。原工作目录存在其他协作者的质感相关未提交改动，未提交、清理或覆盖这些文件。已读取最新AGENTS.md新增的黏土复用规则；本次不改形变、输入、质感参数、换色生命周期或渲染器。

用户最新要求：展示页占满完整一屏，不需要上下翻动。这替代此前短屏“自然滚动”的布局要求。

## 实现

- 页面采用100dvh（100svh回退）的纵向结构。顶部导航按实际高度占位，主区用“标题／弹性主体／底部色卡”三行网格分配剩余空间。
- 移除主体255／290／300px的固定最小高度和主区硬编码高度扣减；容器按实际可用空间伸缩，沿用已有ResizeObserver调整画布与命中区，不重新加载模型。
- 手机保持5×2颜色，桌面和横屏10×1；短屏收紧标题间距、色卡高度和留白，主要触控区域始终≥44px。保留顶部／底部安全区。
- 没有通过overflow:hidden裁切内容。十种颜色、返回入口、标题与真实主体全部留在屏内。首页Hero、第二屏、大厅及3D代码不变。
