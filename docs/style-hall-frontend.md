## 状态边界与后续交接

`collections/styles.mjs`是**前端示意登记**，不是实际模型登记。八项使用稳定展示ID：`orb / cloud / paw / cylinder / donut / pyramid / flower / star`；`previewStyle()`只识别七个替代入口。

新样式链接为 `/squishy/cloud/?style=orb&preview=<展示ID>`。实际渲染配置、制作配方与真实模型登记仍为`orb`，不会把未实现样式当成已生效。`detail/state.mjs`、`detail/adapters.js`、`src/`、模型、质感模板与首页均未改动。`preview`只用于提示、页面标题与返回锚点；未知值会移除，所有文字通过textContent写入。

今后正式样式开发由负责方扩展真实样式登记、模型加载与几何兼容；不能仅去掉替代提示就宣称新造型已经可玩。请读取最新`docs/orb-feels.md`，沿用既有质感工厂与输入／恢复／清理生命周期。本轮没有复制场景或修改黏土、棉花糖、慢回弹的行为，也不从其他协作者未提交工作中移入模板。

原创资源及生成方法见 `assets/style-thumbnails/README.md`，`node scripts/build-style-thumbnails.cjs`可重复生成八张图。仅生成独立SVG，不覆盖原球体或首页样例。
