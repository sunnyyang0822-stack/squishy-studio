# Issue #25：有过程的按下、可见滑痕，原回弹保持

2026-10-23，基于 `origin/main` `2bf30c3`，分支 `codex/issue-25-responsive-pressure`。

用户先后指出阻尼太大、滑痕看不见，以及“先突然凹陷、再慢慢磨”的速度问题。最终要求按下有清楚过程、速度均匀，并确认松手回弹正确、灯光另行统一修改。

## 最终实现

只调整独立慢回弹工厂，不修改黏土、棉花糖、场景、灯光、明暗、材质、色彩或模型。

- 原按压指数逼近改为有界的匀速深度推进，消除前快后慢的尾段。
- `pressSpeed: .45` 模型单位/秒；`pressOnsetSeconds: .12`：先用120ms平滑起步，再匀速压深。完整中心下压约0.82s。
- 起步使用速度线性上升的精确时间积分：`F(t)=t²/(2r)`（t<r），否则 `F(t)=t-r/2`。每帧只使用 `F(t+dt)-F(t)`，避免按帧数累加或刷新率改变手感。
- `dragSpeed: 1.8`，`dragThreshold: .04`：真实路径移动约.04模型单位后逐渐切换为更清楚的滑动反馈。按累计路径长度混合速度，不按事件数量。移动到新位置仅使用当前帧当地接触量，不继承旧压深。
- 每次 begin/release/cancel/reset/beginRestore 清理本次移动距离；实例状态独立，复用原有统一接口和生命周期。
- 原 `initialResponse: 1`、`contactRampSeconds: .10` 保留；初始比例为1时不再叠加当地迟滞，驻留深度仍来自有限速度与当地接触时间。

**释放后的恢复完全保持原样**：`.80/s`；减少动态 `5/s`；收敛阈值 `.00001`；最大深度 `.34`；原换色恢复与输入接管不变。隐藏暂停及资源清理沿用既有协调。

## 实际GLB测量

静止按压中心，60Hz，单位为所有真实顶点与原始位置的最大欧氏距离：

| 首帧16.7ms | .000520 |
| 100ms | .018702 |
| 300ms | .107725 |
| 500ms | .197495 |
| 800ms | .332151 |
| 900ms | .339133 |

120/170/220ms深度约 `.026931/.049374/.071816`，两个50ms间隔都深入 `.022443`，测试误差限 `.000001`。没有首帧突然压深，也没有后段无限减速。100ms仍有起步反馈，约0.82s到达限深。

起点驻留2.5s→滑动.7s→终点驻留1.3s，测量起点旧痕/中段/终点为 `.073205/.077903/.337569`；中段约终点23%。起点在开始驻留时深于中段，之后在终点驻留期间自然恢复，因此不要求较旧的起点始终比较新的中段深。整条路径最终精确归零。

连续滑动.12/.8/4s的最大深度约 `.03885/.26383/.33909`。慢划由于当地停留更久可以更深，但不会反复累积突破上限。新旧凹陷自然精确归位，最终误差0，4s长按释放后约13.05s停止；减少动态约2.10s。原14s上限和.004采样误差容差不变；30/60/120Hz及10Hz输入的最大坐标误差约.002830。

## 局限与回滚

这是径向视觉近似，不宣称真实材料物性。滑动后该次手势继续使用较强反馈，因此终点驻留更容易加深；下一次按压会重新缓慢起步。稀疏事件无法恢复未输入的折线路径，仍沿已知球面补点。灯光另行统一修改，此次不涉及。
