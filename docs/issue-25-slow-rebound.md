## 行为与实现

`src/orb-slow-rebound.mjs` 提供独立工厂，`src/orb-feels.mjs` 登记 `slow-rebound`。`clay` 的默认映射、工厂源码、参数和回归约束保持。现有模型仍为124,324字节的 `squishy-orb.glb`，未新增依赖、模型或纹理。手感 ID 不包含光学参数；场景继续使用 roughness .82、metalness 0、既有色卡与昼夜灯光。

按用户追加要求，慢回弹搭配独立外观 `full-matte`：模型展示缩放 `[1,1.06,1.10]`，高度增加6%、前后厚度增加10%；原始几何和形变坐标不变，命中检测与法线沿用正确的模型变换，接触阴影及姿态恢复使用对应静止高度。十色线性着色增益统一 `.94`，实际sRGB观感小幅加深，色相及色卡标识保持。配置集中于 `src/orb-appearance.mjs`，与手感工厂分离。黏土和棉花糖仍是 `matte`，缩放 `[1,1,1]`、增益1，未顺带改色。

每个顶点独立记录向内位移和当地接触时间。接触核为局部半径内的 `(1-q²)³`，输入路径按归一化静止椭球插值，按路径长度加权分配当前时间步的接触量。压入响应随当地驻留逐渐屈服，不将整次按住时长传播到新位置。反复经过受有限目标深度约束，不叠加永久基底；不会在松开时补造终点凹坑。恢复中的再次按压保留当前位移，旧、新区域最终都归零。

全部可调参数集中于 `slowReboundParameters`：

| 参数 | 值 | 理由 |
| --- | ---: | --- |
| radius | .60 模型单位 | 圆润局部凹陷，控制滑动接触时间和轨迹宽度 |
| maximumDepth | .34 | 长按可见，明显低于穿面深度 |
| radialLimit | 每顶点静止半径的40% | 保持至少60%原半径，禁止越过中心 |
| pressRate | .45/s | 强阻尼的连续压入上限，无振荡或过冲 |
| initialResponse | .10 | 新接触初期阻力，压入速率起始为 .045/s |
| contactRampSeconds | .75s 当地接触量 | 驻留才逐渐压深；移到新位置重新建立接触 |
| contactMemoryDecay | 4/s | 离开接触后当地屈服记忆衰退，减少重复划过的增压 |
| recoveryRate | .80/s | 无弹跳的缓慢恢复；约2.88s消除90%、5.76s消除99%位移 |
| reducedRecoveryRate | 5/s | 减少动态时缩短释放后的运动，按压阻力保持 |
| convergence | .00001 模型单位 | 低于可见像素的残差吸附至精确静止网格 |
| pathSpacing | .035 模型单位 | 稀疏路径连续，控制采样开销 |
| maximumContactStep | .10s | 卡顿时限制单帧压入，避免突然塌陷 |

当新目标更深时采用当地屈服后的压入速率；目标变浅时采用恢复速率。接触事件只更新路径，不直接改变可见位置。`step` 按秒推进，最后残差小于阈值时将所有坐标恢复到原始 Float32 值。静止后返回 `atRest: true, needsFrame: false`，不继续请求无用帧。

`beginRestore` 捕获当前位移，暂停自动回弹；`applyRestore` 使用既有换色进度的三次剩余量，不再叠加自动衰减。新输入和旋转可以中断显式恢复，随后自动回弹接续。换色及姿态恢复沿用原有场景协调，未增加第二套循环或监听。`cancel`、pointercancel、失焦只结束施力；`reset` 同时清空压痕、路径、当地接触和计时，下一帧无旧痕。离页销毁输入和 GPU 资源。

后台策略是暂停：隐藏时结束施力、不渲染；显现时清除旧帧时钟，从当前形态平滑继续。后台经过的墙钟时间不算作持续按压，也不作为一次大步长突然恢复。显式换色恢复同样暂停，前台继续。

## 量测定义与自动验证

使用实际 GLB 的 POSITION、NORMAL、三角形索引。静止基准为每个工厂创建时的原始 POSITION 快照。几何误差是所有顶点与原始位置的最大欧氏距离；恢复完成要求 **每个 Float32 坐标精确相等、最大误差0**，不调用测试重置。恢复中要求持续请求帧，完成后实际浏览器渲染计数停止。

正常模式释放后上限14s；4s长按的60Hz积分约12.79s进入精确静止，减少动态约2.05s。最后一帧最大坐标修正不超过 `.00001`；即使350像素/模型单位，也小于 `.0035` 像素。此阈值有可视依据，既不保留无限残差，也不造成可见末帧跳变。每个顶点单调恢复、每个真实三角形保持朝外，检查有限值和径向边界。

60Hz几何量测（GLB单位；中心点 `[sin(θ), .0175, cos(θ)]`，选最近的实际顶点）：

| 同一操作 | 慢回弹 | 黏土 |
| --- | ---: | ---: |
| 新接触首帧16.7ms最大深度 | .00030 | 约.002 |
| 按住100ms最大深度 | .00258 | 约.0097 |
| 按住3s最大深度 | .23706 | 约.3686 |
| 松开2s后最大深度 | .04786 | 约.3133 |
| 自然恢复完成 | 精确归零并停帧 | 保留压痕并停帧 |

起点θ=-1驻留2.5s → .7s滑到θ=1 → 终点驻留1.3s，松手前起点／中段θ=0／终点约 `.04708 / .00194 / .12722`。中段只占终点约1.5%，端点驻留差异真实来自几何与时间，松开前后没有新增深坑。快速滑过的极浅响应不要求达到驻留端点的深度。

30/60/120Hz及60Hz渲染配10Hz输入回放同一2秒路径：最大坐标误差约 `.000607 / 0 / .000305 / .002589`，限值 `.004`（最大压深的1.2%以内）。这允许10Hz输入无法表达的事件间运动时间差，同时限制可感知的采样依赖；不是实测设备帧率。覆盖快划.12s、慢划.8s、长划4s、折返、交叉、重复揉压、稀疏跨越、长按后新位置、恢复中再次按压和全路径归零。

独立测试还覆盖：深按及六方向18s长按、换色时钟独占、快速重启恢复、新输入接管、cancel/reset、减少动态切换、实例/资产隔离。浏览器通过真实 GPU 顶点上传验证鼠标与原生CDP触摸、换色中断、pointercancel、失焦、后台冻结和连续恢复、离页上下文释放。既有黏土测试不弱化。

## 局限与回滚

这是受控径向视觉近似，没有体积守恒、真实填充物、触觉反馈或经过材料标定的应力曲线。模型比例和凹形变化后需重新验证；本轮仅对现有归一化圆球验收。低采样无法还原事件之间未传入的折线路径，补点沿已知球面段；卡顿限制单帧压入，可能拉长按压达到深度的墙钟时间。真机触感仍需实机复核。

回滚本 PR 相对 `959a719` 的变更并重建，即可移除独立登记、`butter` 映射及协调修订，恢复 #22 原有三种选项均使用黏土的状态；黏土工厂无需恢复参数，没有数据或资产迁移。若采用合并提交，正常 `git revert -m 1 <本PR合并提交>` 即可保留 #22。关联 #25、#16、#22、#3，不自动关闭其他范围更大的 Issue。
