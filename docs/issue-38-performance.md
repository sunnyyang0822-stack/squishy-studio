## 查询瓶颈与验证原则

独立 CPU 采样确认主要开销来自薄蜡同步中的实时芯三角面查询。有限线段 AABB 裁剪、最近点距离平方比较、当前几何上的初始候选面、标量包围盒计算，以及同一片内完全相同的共边中点查询去重均保留原本的独立采样位置和完整搜索结果。没有减少壳片预算、碰撞采样、厚度、阴影或内芯精度。

共边去重阶段的单独采样共完成 47 帧：平均每帧 22,613.6 次最近面查询，其中附着层 21,317.3 次、碎片 1,296.3 次；实际线段查询 37,073.6 次，原逻辑位置 51,625.3 次。附着层最近面查询仍为主要瓶颈。摘要见 `artifacts/issue-38/paw-query-profile-hotspots.json`；采样工具自身开销不能冒称非采样帧耗时。

`tests/wax-collision-query.test.cjs` 使用独立的逐三角面穷举对照，检查动态 refit、正负方向、平行轴、包围盒边界、内部起点、短线段与最近面的数值结果。每轮算法调整先做查询对照及圆球／猫爪／甜甜圈实际几何检查，最终还需运行八款完整几何和原圆球回归。优化后的独立帧耗时与最终运行包须另行登记，不以中间版本数据宣称完成。

## 复杂曲面的完整近距离索引

附着层的查询位置密集且大多靠近已知支撑面，单独增加三角面空间索引作为宽阶段：每次 refit 把实际当前三角面的整个 AABB 放入所有相交格子。查询先在当前几何上重算候选面最近点，取得距离上界，再搜索点周围覆盖该上界球体的全部格子；真正最近面必然包含在此范围内。候选仍逐面执行与 THREE.Triangle 等价的最近点数学，未省略采样位置。

索引仅为已有复杂曲面开启，格宽 0.025 模型单位，最多 1,000,000 格和 1,000,000 链接；头与链接 TypedArray 合计上限约 12MB，另有每源面查询标记和现有 BVH。大范围查询、超出索引区域、预算溢出，以及最近面距离相等／数值近似相等时，均回退完整实时 BVH，保留其等距面选择和法线。圆球路径不创建这份格索引。节点／三角面计数仅由诊断 `thinWaxDiagnostics({counters:true})` 显式启用，普通性能测试不开启。

新增索引测试实际命中圆球／猫爪／甜甜圈的局部面心、边和顶点，正负间隔、动态 refit 与超界移动均与完整 BVH 对照；实际走到格索引的查询分别超过 1,400 次，而非只测回退路径。原 BVH 又独立对照全三角面穷举。等距法线、近距离 signed 值与全局回退一致；完整几何测试继续检查实际壳面、边和断面。

中间版本独立猫爪测试达到中位数 45.9ms / P95 54.2ms（`grid-fine-after-paw.json`），相对初始基线有明显改善，仍不能称为手机流畅验收通过。最终九个支持组合的独立采集入口为 `node scripts/benchmark-wax-presets.cjs`，输出 `final-performance-<style>-<core>.json`、汇总与逐条命令／退出码；采集成功与性能合格分开报告。
