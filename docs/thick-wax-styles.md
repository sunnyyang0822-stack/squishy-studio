# 厚蜡其他黏土样式（Issue #43，排除猫爪）

继圆球用户验收后，复用相同 `thick-wax` 预设接入 **云朵 cloud、圆柱 cylinder、甜甜圈 donut、三角锥 pyramid、五瓣花 flower、五角星 star**。猫爪按用户要求不启用，棉花糖和慢回弹也不扩展。圆球已批准合并，这六款作为新的视觉审查版本交付。

## 实现与流程

不重新调参：仍使用 `thickWaxParameters` 的 thickness=0.042、seedCount=36，其余全部沿用已验收薄蜡行为。薄蜡厚度0.014、安全间隔0.004、0.5秒驻留、最多3片首轮掉落、后续真实损伤释放、速度、清理与内芯阻力均未改变。未改内芯、模型、灯光、展示缩放、默认配方或布局。

`src/wax-preset-scope.mjs` 仅提供只读允许列表，不依赖Three.js；原生浏览器加载的 `detail/state.mjs` 不可导入包含Three裸导入的工厂。`src/wax-presets.mjs` 继续提供 `getWaxPreset('thick-wax').create({styleId, ...})` 并重导出范围列表；场景复用原输入、生命周期、分块和BVH，无新的循环/监听器或碰撞分支。

新六款仅在制作外壳、装饰页显示厚蜡，沿用薄蜡当前支持边界。最终体验继续原裸内芯恢复；隐藏的制作壳损伤保留，返回制作显示原破口。显式重开或配方变化才重建损伤。原黏土圆球最终厚蜡收集行为不变。

### 局部厚度与防穿模

每款246帧场景包含结构连接处（甜甜圈为真实内壁）深压、分离、拖动、旋转、重复按压、松手恢复和显式恢复。关键阶段逐个检查完整内外层的顶点、边中点、三角面心及侧壁，包含实际脱落片及其运动序列；每个活动内外顶点对保持 **0.042局部实体厚度**，误差要求<0.00001。清理后归零的片不当作厚度样本。与裸黏土基线逐点完全相同，壳不会关闭或改变内芯形变。

六款全部通过，无需更改共享防穿模或开启另一套支撑路径。总计18,041,912次独立完整几何采样，最小有符号距离0.003049908877，最大局部厚度误差3.2633e-7。甜甜圈独立日志 `geometry-donut.txt` 约293万完整内外壁采样，无穿入。数值测试覆盖所列资产和有限操作序列，不代表任意非凸模型/任意动作的数学保证。
