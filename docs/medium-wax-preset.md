# 可复用黏土中蜡（Issue #41）

已确认的中蜡保存为 `getWaxPreset('medium-wax')`：实体厚度 0.028（薄蜡 0.014 的两倍）。圆球保持96个原球域种子；非圆球按用户走查要求扩大实际碎块，并专门解决甜甜圈内环和猫爪凹陷处的小片：猫爪32个实际表面种子，其他六款48个实际表面种子。参数与优化方案均归预设所有，调用方只传 `styleId`，不自行拼装配置。接入全部八款已有黏土样式：圆球、云朵、猫爪、圆柱、甜甜圈、三角锥、花朵、五角星；其余内芯和材料不扩展。支持步骤沿用各款薄蜡合同：八款外壳／装饰预览，圆球原有最终试捏；非圆球最终试捏仍保持原单层呈现，隐藏中蜡并保留损伤，返回设置可继续原中蜡。内芯步骤隐藏壳体，制作准备阶段结束输入，默认配方和布局不变。

猫爪中蜡通过预设启用既有 `fullSurfaceSupport`，以真实闭合芯面检查内外层与断面；圆球及其他款保留原支撑配置。首轮猫爪第二次趾根深压出现附着断面／碎片违规，开启该既有能力后同操作完整检查通过。没有降低精度、减少边缘采样或改变容差；不修改薄蜡和内芯模板。每款实际片数以连通岛拆分及预算回退结果为准，不把96个种子混称为96个最终实体片。

开发起点为 `origin/main` 的 `3acd470`，最初引入已提交薄蜡 `1185cfc`，未纳入或提交他人工作树的未提交成果。开发期间正式薄蜡交付进入 main，最终本地分支同步至 `0406a4ac8e92c078b3da5ccd4299d6acdf9817f2`，以该版本为最终回归基线。本轮仅本地开发、测试及 commit，按用户要求不推送、不创建 PR、不合并。

```js
import { getWaxPreset } from './wax-presets.mjs';
const preset = getWaxPreset('medium-wax');
const parameters = preset.parametersForStyle('paw'); // 冻结：0.028 / 32 / surface
const geometryOptions = preset.geometryOptionsForStyle('paw'); // 冻结的优化方案
const wax = preset.create({ styleId: 'paw', geometry: core.geometry, restPositions, restNormals,
  color: '#f2b3ce', worldMatrix: core.matrixWorld, collectionEnabled: false });

```

输入、时钟、内芯先形变后更新壳体、松手结束、离页释放均沿用 [薄蜡契约](thin-wax-preset.md)。`parameters` 是圆球／未指定样式的基准；`parametersForStyle(styleId)` 返回该款实际只读参数，`geometryOptionsForStyle(styleId)` 返回只读优化配置，`create` 自动应用两者。每个实例独立分配材质、几何、损伤、查询提示、距离证书、碎片与时钟。`thin-wax` 参数对象及默认工厂路径保持不变，包括最新主线猫爪／甜甜圈 small 分块选择。

## 非圆球局部大块与预设内优化（当前版本）

原种子位于单位球域，裁切平面穿过模型原点；全壳面积较大并不代表内环和凹处不是窄碎片。中蜡非圆球改为按实际原始三角面面积采样、带最小间距的确定性表面种子，Voronoi平面采用两个实际种子的中垂面。它只扩展原分区裁切器的种子与平面偏移配置；原始三角面裁切、重心坐标映射、真实连通岛拆分、邻接、开裂、输入、掉落和清理仍为同一套实现。圆球和所有薄蜡继续原球域分区；没有放大已脱落片，也没有合并跨孔的不连通片。实际闭合断面厚度与壳芯间隔不变。

`geometryOptionsForStyle` 中保存以下优化；默认为薄蜡关闭，只有中蜡工厂自动启用：

- `freezeRenderedFragments`：冻结分离前实际显示形状与法线，防尺寸跳变。
- `detachedQueryHints`：每个实际碎片采样点有独立最近面提示与运动界证书；完全相同的世界碎片在局部芯面上仍作完整检索。三角面中心的正距离球可保守证明边中点安全；每个边中点仍检查是否在球内，不能通过证书时查询原BVH，保留10次整体平移校正。复用工作向量与证书对象，减少逐帧分配。
- `supportClusters`：将同源三角面上的外层采样组织起来，用一次真实最近面距离构成安全球；每个采样点仍按当前位置判断，其他断面校正导致其越界时立即回退原查询。内层、边缘、壁面、校正迭代及容差不删减。
- `featureTieConsensus`：仅在空间索引所有等距候选的最近点、角加权特征法线、正负号与距离一致时接受该结果；点／法线平方误差须小于1e-24、距离差小于1e-12，任何歧义继续完整BVH。没有用任意面的法线掩盖凹陷穿模。
- `fullSurfaceSupport`：猫爪额外开启现有完整内外层／断面支撑及闭合表面特征法线，其他款保持原设置。

`tests/medium-wax-optimization.test.cjs` 对同一真实猫爪、相同32表面分区，比较优化预设与关闭提示／证书／分组／特征等距快速返回的原查询路径。80帧涵盖趾根和侧凹深按、拖动与释放，所有Float32位置和法线最大差异为0；输入／损伤／碎片状态一致，完整几何0穿入。最近面查询886,335次对5,880,438次，约为参考路径15.07%。查询减少来自保守证明与复用，不是删掉独立采样位置。原薄蜡、完整BVH／逐面扫描、角加权法线及内芯回归另行保留。

## 最小实现差异与生命周期

中蜡通过 `thickness`、`seedCount` 与 `partitionSpace` 表达尺寸差异；驻留 0.5 秒（严格超过后碎裂）、连续应变触发、输入规则、碎片速度、重力、24 活动／180 总预算、损伤与清理规则继承薄蜡。猫爪和甜甜圈薄蜡继续使用主线small预设，中蜡由预设选取圆球96／猫爪32／其余48种子配置。最新逐款统计见 `artifacts/issue-41/large-final-regression.txt`，早期96种子统计 `all-clay-medium-summary.json` 仅为历史对照。平均块更大来自实际 Voronoi 裁切分区，不改变碎片显示比例，也不增加粒子或掉落数量。

大块分离启用内部 `freezeRenderedFragments`：首次成为自由碎片时冻结最后已显示的附着形状及法线，直接传给原掉落／碰撞模块。它防止按原始芯面重新建片时在较大断口产生尺寸跳变；不改变速度、碰撞采样、驻留或应变参数。薄蜡不启用该选项。回归逐点验证分离前后距离不变，以及原内外层厚度保持。

深压、重叠按压、拖动、释放恢复在三个世界旋转角度下逐阶段进行完整几何检查：附着顶点、面中点、边中点、断面，以及脱落片的整体内点与边。零违规只代表已采样状态，不承诺任意连续时间或其他模型均无交叉。三种内芯源码和光学外观未修改。

切换薄／中、颜色或有效配方使用原 `recipeKey` 和修订号机制：已生效的新配方销毁旧壳与碎片，最后选择生效；同一轮未提交的中间配置若最终回到当前配方，则按薄蜡既有契约保留损伤。往返步骤不修复损伤，重新开始主动恢复，离页释放。测试检查重复切换后实际渲染器几何资源数量回到基线。
