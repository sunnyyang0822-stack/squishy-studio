# 可复用黏土中蜡（Issue #41）

已确认的中蜡保存为 `getWaxPreset('medium-wax')`：实体厚度 0.028（薄蜡 0.014 的两倍），96 个 Voronoi 种子。按用户后续授权接入全部八款已有黏土样式：圆球、云朵、猫爪、圆柱、甜甜圈、三角锥、花朵、五角星；其余内芯和材料不扩展。支持步骤沿用各款薄蜡合同：八款外壳／装饰预览，圆球原有最终试捏；非圆球最终试捏仍保持原单层呈现，隐藏中蜡并保留损伤，返回设置可继续原中蜡。内芯步骤隐藏壳体，制作准备阶段结束输入，默认配方和布局不变。

猫爪中蜡通过预设启用既有 `fullSurfaceSupport`，以真实闭合芯面检查内外层与断面；圆球及其他款保留原支撑配置。首轮猫爪第二次趾根深压出现附着断面／碎片违规，开启该既有能力后同操作完整检查通过。没有降低精度、减少边缘采样或改变容差；不修改薄蜡和内芯模板。每款实际片数以连通岛拆分及预算回退结果为准，不把96个种子混称为96个最终实体片。

开发起点为 `origin/main` 的 `3acd470`，最初引入已提交薄蜡 `1185cfc`，未纳入或提交他人工作树的未提交成果。开发期间正式薄蜡交付进入 main，最终本地分支同步至 `0406a4ac8e92c078b3da5ccd4299d6acdf9817f2`，以该版本为最终回归基线。本轮仅本地开发、测试及 commit，按用户要求不推送、不创建 PR、不合并。

```js
import { getWaxPreset } from './wax-presets.mjs';
const preset = getWaxPreset('medium-wax');
const wax = preset.create({ geometry: core.geometry, restPositions, restNormals,
  color: '#f2b3ce', worldMatrix: core.matrixWorld, collectionEnabled: false });
core.add(wax.group);
```

输入、时钟、内芯先形变后更新壳体、松手结束、离页释放均沿用 [薄蜡契约](thin-wax-preset.md)。`parameters` 和注册项冻结，每个实例独立分配材质、几何、损伤、碎片与时钟。`thin-wax` 参数对象及默认工厂路径保持不变，包括最新主线猫爪／甜甜圈 small 分块选择。

## 最小实现差异与生命周期

中蜡仅覆盖 `thickness` 和已有分区配置 `seedCount`；驻留 0.5 秒（严格超过后碎裂）、连续应变触发、输入规则、碎片速度、重力、24 活动／180 总预算、损伤与清理规则继承薄蜡。猫爪和甜甜圈薄蜡继续使用主线small预设，中蜡仍使用独立96种子配置。逐款平均／中位面积、覆盖与实际片数见 `artifacts/issue-41/all-clay-medium-summary.json`。平均块更大来自实际 Voronoi 裁切分区减少，不改变碎片显示比例，也不增加粒子或掉落数量。

大块分离启用内部 `freezeRenderedFragments`：首次成为自由碎片时冻结最后已显示的附着形状及法线，直接传给原掉落／碰撞模块。它防止按原始芯面重新建片时在较大断口产生尺寸跳变；不改变速度、碰撞采样、驻留或应变参数。薄蜡不启用该选项。回归逐点验证分离前后距离不变，以及原内外层厚度保持。

深压、重叠按压、拖动、释放恢复在三个世界旋转角度下逐阶段进行完整几何检查：附着顶点、面中点、边中点、断面，以及脱落片的整体内点与边。零违规只代表已采样状态，不承诺任意连续时间或其他模型均无交叉。三种内芯源码和光学外观未修改。

切换薄／中、颜色或有效配方使用原 `recipeKey` 和修订号机制：已生效的新配方销毁旧壳与碎片，最后选择生效；同一轮未提交的中间配置若最终回到当前配方，则按薄蜡既有契约保留损伤。往返步骤不修复损伤，重新开始主动恢复，离页释放。测试检查重复切换后实际渲染器几何资源数量回到基线。
