# 中蜡预设 medium-wax（Issue #41）

预设名称：**中蜡·双倍薄蜡厚度**。代码名称保存在 `getWaxPreset('medium-wax').name`；稳定调用 ID 为 `medium-wax`，后续查找、复用均使用该 ID。名称只作识别，不改变参数或支持范围。

用户已授权提交并合并七种非猫爪样式×三种内芯的21个中蜡组合及本预设。原薄蜡交付基线为0406a4ac8e92c078b3da5ccd4299d6acdf9817f2；本次已集成origin/main的257d546，保留后续薄蜡、厚蜡、指甲油与圆球几何交付。仅操作本任务PR，不关闭#38或#22。仓库保持Public。

## 调用与范围

```js
import { getWaxPreset } from './wax-presets.mjs';
const preset = getWaxPreset('medium-wax');
const wax = preset.create({
  styleId: 'donut', geometry: core.geometry, restPositions, restNormals,
  color: '#efb3c9', worldMatrix: core.matrixWorld, collectionEnabled: false,
  fullSurfaceSupport: true, // 非圆球棉花糖／慢回弹的宿主显式传入
});
core.add(wax.group);
```

登记为material:wax、thickness:medium。内芯独立使用getOrbFeel('clay'|'marshmallow'|'slow-rebound')；制作配方butter映射slow-rebound和full-matte，其他内芯沿用原外观。没有复制工厂、场景或碎裂系统，没有改三种手感参数。

| 内芯 | 外壳／装饰预览 | 最终试捏 |
| --- | --- | --- |
| 黏土 | 圆球、云朵、圆柱、甜甜圈、三角锥、花朵、五角星 | 保留已有圆球中蜡；其余沿用原流程 |
| 棉花糖 | 上述七种样式 | 原最终体验，不新增中蜡 |
| 慢回弹 | 上述七种样式 | 原最终体验，不新增中蜡 |

内芯步骤裸芯试捏、制作步骤隐藏。配方不变时外壳／装饰导航保留损伤；预览专用配方进入最终体验时restore({preserveShell:true})保留隐藏壳。真正提交配方变化、显式重开按既有规则重置；过期异步准备销毁，最后选择优先。内外颜色独立，沿用换色恢复和离页释放。

薄蜡仍映射thin-wax；厚蜡、指甲油、糖不会映射中蜡。本交付不实现它们，也不扩大模型范围。未知组合不降级冒充支持。

## 复用和性能配置

点击裂缝、驻留时序、持续应变触发、松手停止新增损伤、损伤保留、重开、掉落速度、清理和预算沿用原薄蜡／中蜡契约。真实内外面、边中点、断面及扫掠检查保留；没有用透明度、renderOrder或关闭深度测试掩盖穿模。

performanceOptimizations默认false，仅中蜡非圆球非猫爪只读几何配置启用：

- 只重登记实际跨查询格的变化面，格内仍用当前真实坐标；超界或容量不足回退完整BVH。
- 逐顶点标记变化以减少重复读取；复用候选数组、向量、变化包围盒和未变化三角面的特征角度。
- 附着板片只在全部源顶点位置／法线／变形标记、裂边及损伤状态均未变化且附近无变化芯面时复用；重开清空。
- 最近／次近证书保留未访问区域保守界限；移动碎片保持精确signedDistance，原采样和修正迭代不删减。

freezeRenderedFragments、detachedQueryHints、supportClusters和featureTieConsensus沿用中蜡配置；支持区域必须精确通过，否则回退原查询。猫爪128表面种子等历史实验配置仅供回归诊断，不属于已启用的21个组合，三种内芯的猫爪中蜡均不启用。非圆球棉花糖／慢回弹由宿主传入fullSurfaceSupport；这两种内芯的猫爪在流程排除。

慢回弹几何适配另可选cacheSafety:true，只复用原margin下已证明整个[0,1]位移段安全且from/to顶点版本相同的结果。校正或实际坐标变化即失效，原多项式、8%面积裕量、修正、最终完整验证和异常不变。静态厚度索引从首次输入移到场景准备。圆球、猫爪和其他内芯不启用；工厂手感参数不改。
