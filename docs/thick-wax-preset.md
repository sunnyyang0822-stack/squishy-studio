## 调用与范围

```js
const preset = getWaxPreset('thick-wax');
const wax = preset.create({ geometry, restPositions, restNormals, color, clock, worldMatrix });
```

`src/wax-presets.mjs` 登记只读厚蜡配置；`createWaxShell` 复用原 `createVoronoiWax` 与真实网格 BVH，薄蜡继续使用原 `createThinWax`、原参数及猫爪/甜甜圈小碎片逻辑。每个实例独立持有几何、材质、损伤与碎片状态。未知 ID 明确报错。主线尚无中蜡登记，本轮不补做中蜡。

制作页「蜡＋厚」只为黏土圆球启用，外壳、装饰与既有圆球最终试捏沿用同配方损伤；制作页不显示收集盘，最终页沿原机制显示收集盘。重开、换色、切换配方和离页走原恢复/释放生命周期。默认仍为中厚度；指甲油、糖、其他模型、棉花糖和慢回弹不启用厚蜡。三种内芯源码与行为均未修改。

## 几何参数与实测

单位均为归一化资产的**模型单位**（不是米/毫米）。模型、内芯尺寸、展示变换、光学材质及安全间隔均未更改。

| 项目 | 薄蜡 | 厚蜡 |
| --- | ---: | ---: |
| 实体局部厚度 | 0.014 | 0.042（3倍） |
| 壳芯安全间隔 | 0.004 | 0.004 |
| 真实连通分区数 | 180 | 36 |
| 原始表面平均分区面积 | 0.06671903459 | 0.33359517293（5倍） |
| 等效直径比 | 1 | 2.23607 |
| 厚蜡面积范围 | — | 0.0963588414–0.6117765082 |
| 厚蜡面积变异系数 | — | 0.35178548 |
| 相同正面首轮实际掉片平均面积 | 0.05295874402 | 0.43761328509（8.263倍） |

尺寸增加来自真实 Voronoi 切分源三角形，分离前后保留相同索引和源面映射，不缩放脱落碎片，不增加首轮掉片数（仍最多3片）、触发阈值或掉落速度。探索40种子后，其面积变异系数0.342低于原不规则度回归要求，因此最终选择36种子；最终录屏全部重新构建采集。面积倍率不是每一对随机碎片的保证，平均与首轮实际掉片分别量测。

**局部厚度约束同样为3倍，不能用全局平均值达标。** 每个活动壳体内外顶点对距离必须保持0.042，最大容差0.00001；已清理且归零的片不作为厚度样本。脱落曲面刚性模板保持边长与局部厚度。所有后续样式必须单独验证局部断面、薄处、内圈、连接处与完整内外壁，不得从圆球结果推断非凸模型通过。当前不启用其他样式。

## 风险与回滚

大碎片覆盖的破口更大；同数量碎片的实际脱落面积增加是本任务预期行为。几何安全复用原算法，不使用透明度、renderOrder 或关闭深度测试。原默认指标主要采样内表面；新增独立测试明确补齐外表面、边及侧壁，未弱化既有断言。其他样式和内芯的厚蜡仍未验收；尤其非凸内圈和连接处需专项验证。

回滚本分支厚蜡提交并 `npm run build` 即可恢复薄蜡单预设与原流程映射，无数据或资产迁移。尚未合并，不影响远端 main；审查前保持独立分支和可操作预览。
