裂纹先粗后细，细层从父裂纹邻域发展并融合线宽。持久damage、当前芯位移opening和慢回弹残余收缩residual分别管理。一次begin到end对当地顶点最多计一次接触，增量由实际局部峰值控制，固定数组和宽度上限。非圆球沿真实表面邻域与路径，避免跨甜甜圈空孔串扰。
