# Squishy Studio｜虚拟脆皮捏捏

一个正在规划中的中文虚拟解压网站，让用户直接在浏览器中体验拟真 3D 脆皮捏捏玩具，感受局部挤压、脆皮碎裂、柔软回弹与同步 ASMR 音效。

## 产品目标

- 打开网页即可开始体验，无需安装或注册账号。
- 通过按压、拖动和松开，获得自然、连续的形变反馈。
- 将清脆的表面碎裂与柔软的弹性回弹结合起来。
- 使用与动作同步的 ASMR 音效，并提供明确的声音开关。
- 兼顾桌面鼠标与手机触屏操作。

## 语言与视觉方向

- 网站默认使用简体中文，导航、操作提示、按钮和状态反馈均采用中文文案。
- 项目说明与面向用户的文档优先使用中文，保留 Squishy Studio 品牌名称。
- 视觉以拟真 3D 为主，营造安静、精致的数字解压工作室氛围。

## 首版范围

先做好一个玩具和一套完整的脆皮与软芯体验，再根据验证结果考虑更多材质和玩具。

首版聚焦页面体验、玩具表现、核心交互、音效和移动端适配。账号、支付、社交、收藏和多玩具商城暂不纳入首版。

## 阶段规划

1. **页面 UI 与视觉框架**：确定中文页面结构、视觉层级、操作控件和响应式布局。
2. **正式 3D 玩具与材质**：规划并验证模型、材质、光影与渲染表现。
3. **核心交互**：实现按压、拖动、局部形变、脆皮反馈与弹性恢复。
4. **声音与材质差异**：完善 ASMR 音效与动作同步，再评估材质扩展。
5. **体验优化与上线准备**：完成性能、兼容性、加载、基础 SEO 和上线验收。

## 当前状态

样式大厅 `/collections/` 提供圆球及七款真实可制作模型：云朵、猫爪、圆柱、甜甜圈、圆钝四面体、五瓣花朵和五角星。七款新模型支持黏土、PR #32 已确认的渐进棉花糖及已确认慢回弹预设；选择后加载对应 GLB，沿用五步制作和最终试捏。猫爪按参考改为圆厚掌体、四个凸起趾垫和饱满倒心形主垫。源文件、导出及初次交付见[七款黏土交付说明](docs/issue-30-clay-styles.md)，本轮修订与验证见[猫爪及预设修订](docs/issue-30-paw-revision.md)。

首页第二屏展示云朵、猫爪、甜甜圈与花朵，点击图片或名称进入对应真实模型的黏土制作流程。也可通过「去合集大厅挑选」查看八种样式。本轮接入保留已交付的页面设计、Hero及配方逻辑。

新增奶油小云详情页 `/squishy/cloud/`：独立静态外观预览、脆皮厚度与材质选择、音量偏好面板。可从大厅的「查看小云外观预览」进入；不代表玩具已经可捏压。详情页复用昼夜偏好，支持直接打开、刷新和返回合集。

详情页、首页第二屏与大厅的捏捏在昼夜模式下保持素材原色。控件提供轻量按下反馈、可反向连续操作的音量面板过渡，并兼顾键盘与减少动态偏好；[原色与动效验证](docs/toy-colors-motion.md)包含最新截图和录屏。

## 本地运行

```bash
npm install
npm start
```

浏览器打开 `http://127.0.0.1:4173`。按 `Ctrl+C` 停止服务。

可直接访问 `http://127.0.0.1:4173/collections/`，刷新仍可打开。返回首页链接定位到 `/#samples`；浏览器返回沿用原生滚动恢复。昼夜偏好保存在本机 localStorage，导航时在样式加载前读取；存储被浏览器禁用时页面仍可使用，但跨页偏好无法持久保存。

## 验证与素材

```bash
npm test
npm run capture
npm run capture:showcase
npm run capture:detail
```

测试通过 Playwright 使用本机 Edge；其他系统可先执行 `npx playwright install chromium`。也可用 `PLAYWRIGHT_BROWSER_PATH` 指定浏览器可执行文件。截图与昼夜切换录屏保存在 `artifacts/`。

`capture:showcase` 需要先启动预览服务，在五种视口生成第二屏、大厅与图片失败截图，并对照本次保存的 Hero 基准图。基准图来自 Windows Edge，像素比较应在相同环境执行；CI 使用浏览器行为和原有 Hero 源码指纹回归，不将不同系统的字体渲染当成相同像素。导航录屏和前后对照位于 `artifacts/issue-8/`，详情见 [第二屏交付记录](docs/issue-8-delivery.md)。

第二屏由 `showcase.css`、`showcase.js` 和 `assets/samples/` 独立维护，没有新增 WebGL 场景或依赖。四只样例为本项目原创 SVG 插画，来源与替换方式见 [样例资源说明](assets/samples/README.md)。

品牌字标由 `src/brand3d.js` 使用 Three.js 生成真实挤出网格、圆角倒角与昼夜灯光；`npm start` 和 `npm test` 会先执行 `npm run build:brand`，生成浏览器脚本和 Fredoka 字形数据。WebGL 不可用时显示 SVG 备用字标。字体与 Three.js 授权文本分别见 `assets/FREDOKA-LICENSE.txt` 和 `assets/THREE-LICENSE.txt`。未来的主体交互可从 `brand-stage` 和独立的 3D 模块接入。

详情页没有新增依赖、Canvas 或音源。`detail/state.mjs` 管理独立资源、配置、音频状态；`detail/adapters.js` 预留渲染与主音量接口。接入方式、静态资源来源、测试结果及截图录屏见 [详情页交付记录](docs/issue-10-delivery.md)。`capture:detail` 需要运行当前预览服务，并将 `BASELINE_URL` 指向同环境下运行的明确 `origin/main` 基线；`PREVIEW_URL` 默认是 `http://127.0.0.1:4173`。截图及录屏写入 `artifacts/issue-10/`。
