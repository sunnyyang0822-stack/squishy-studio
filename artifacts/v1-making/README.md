# 首版制作流程与独立壳片：阶段交付

依据 Issue #3 全文和 2026-11-21「首版流程收敛与绘画移至第二版」。基线 origin/main `c140b5c`。新页面 `/make/`，合集选造型后进入内芯；旧 `/squishy/cloud/` 保持兼容，不作为首版主入口。

## 实际完成

| 环节 | 交付 |
| --- | --- |
| 选造型 | 七种首版入口；猫爪保留展示并标为暂停，无制作入口。首页首屏不变，下方样例接新入口 |
| 内芯试捏 | 黏土、棉花糖、慢回弹和原十色；复用主线真实模型、手感与换色，不修改预设参数 |
| 独立壳片 | 两块闭合弧面实体，蜡皮雾面／较宽高光，指甲油亮膜／清楚反光；慢转、点击选择、未选弱化、拖动／按钮转向、减少动态、隐藏停帧 |
| 配置 | 芯色独立；蜡皮与指甲油各自保留颜色，蜡皮薄中厚；非蜡有效厚度 null；返回修改与合集重选造型保留选项 |
| 合成 | 选中样本短汇聚过场；等真实成品准备完成后进入交互；可返回修改／继续，失败可重试，不出现假百分比 |
| 成品 | 基线真正已支持的组合可玩，可手动恢复当前配方完整壳与内芯；未接入组合明确拦截，不裸芯降级 |
| 稳定性 | 快速请求最后生效，切到壳片释放旧芯全局监听；恢复／切步／失败／取消／离页有真实浏览器测试 |

首版不展示绘画、填充物、糖壳、账号、支付、签到及未交付的保存／音量按钮。作品保存和音频是其他执行者的首版任务，**未实现并不等于从首版删除**。

## 返回修改、刷新与重建

壳片切材质、颜色、厚度重用同一个壳片 Canvas，只厚度修改时更换样片几何；不创建新的玩具场景。内芯换造型／质感遵循原适配器重建，换色沿用原覆盖动画。阶段切换会释放旧芯／成品宿主；再次返回试捏按原工厂重建，不保留损伤，保留全部选择。成品“恢复成品”调用原恢复机制，不改配方。合成后返回修改并再次合成，重建新完整成品。

URL 只记录已选枚举与独立颜色偏好，不做存储。刷新 core/shell/play 可以重建合法阶段，making 刷新回 shell；不支持成品组合的 play 直达回 shell 并提示。浏览器前进后退取消过期准备并恢复合法配置。没有“已永久保存”之类表述。
